# BIST AI Analiz Motoru

BIST hisseleri için yapay zeka destekli analiz ve portföy optimizasyonu.

## Özellikler
- 📊 Gerçek zamanlı hisse verileri (Yahoo Finance)
- 🔍 Teknik analiz göstergeleri
- 💰 Portföy optimizasyonu
- 📈 Mevduat karşılaştırması
- 🗄️ MongoDB veri saklama

## API Endpoints
- `/api/hisseler` - Tüm hisseler
- `/api/hisse/{kod}` - Hisse detayı
- `/api/scan` - Hisse taraması
- `/api/portfolio` - Portföy optimizasyonu
- `/api/mevduat` - Mevduat hesaplama
- `/api/compare` - Karşılaştırma

## Deployment
